# Code of conduct

Pip is kind, honest and patient. We'd like this project to feel the same.

- **Be kind.** Assume good faith, explain instead of judging, and remember that many contributors write in their
  second or third language.
- **Be welcoming.** Questions from beginners are as welcome as patches. No one should feel stupid for asking.
- **Disagree on ideas, never on people.** Harassment, insults, discrimination or unwanted personal attention are
  not tolerated, here or in any space linked to the project.
- **Respect privacy.** Don't post anyone's dictations, logs with personal data, or private information.

If something goes wrong, contact the maintainers privately through a GitHub security advisory or the email on the
maintainer's GitHub profile. Reports are handled confidentially. Maintainers may edit or remove contributions and
block people who don't follow this code.
